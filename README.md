# Room Forge — гигахрущ

Редактор комнат-компонентов и генератор карт. Собираете библиотеку типовых помещений хрущёвки
с мебелью, спотами спавна и метками стыковки. Генератор складывает из них карту и разыгрывает
наполнение: споты, лут, элитность и опасность. Результат выгружается в JSON для движка.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/index.html — одна самодостаточная HTML-страница
npm test           # vitest: модель, генератор, пресеты
```

Собранный `dist/index.html` работает без сервера: достаточно открыть файл в браузере.
Проект автоматически сохраняется в `localStorage`.

## Вкладки

| Вкладка | Что делает |
|---|---|
| **Комнаты** | Список комнат и слои. На холсте рисуется форма (прямоугольник, эллипс, кисть; добавление и вычитание, Shift инвертирует), ставятся двери, метки, декор и споты. Инспектор показывает свойства комнаты и выделенного объекта, веса генерации, элитность, группы спотов с таблицей вариантов и лут. |
| **Библиотеки** | Декор (габариты в метрах, текстура вида сверху ≤ 512 px) и предметы. Показывает счётчики использования. Удаление каскадное. |
| **Экономика** | Тиры элитности с лутом по ступеням «до N — P%», карта элитности (комнаты × тиры), магазины и ветки закупки, проходки, лимит опасности. Есть «карточка для игрока» с понятными правилами. |
| **Генератор** | Пробный прогон по сиду: раскладка, что выпало на спотах, лут, тиры. Режимы подсветки: опасность, тиры, глубина. Путь от старта до выбранной комнаты. |
| **3D** | Болванка прогона или комнаты в Babylon.js: стены без наложений, перемычки над проёмами, потолки, мебель-боксы. Облёт и ходьба от первого лица с коллизиями. Экспорт `blockout.json` и `.glb`. |
| **Данные / JSON** | Экспорт компонентов и готовой раскладки, импорт, сброс к пресетам, объём хранилища, справка по формату. |

### Горячие клавиши редактора

`1`–`8` / `V` — инструменты · `X` — добавить/вычесть · `Shift` — инверсия (для формы) или без привязки (для декора и спотов) · `Q`/`E` — поворот ±90° (с Shift ±15°) · `Del` — удалить · `Esc` — отменить жест или снять выделение · `F` — вписать · `Ctrl+Z` / `Ctrl+Shift+Z` — отмена и повтор · колесо — масштаб · средняя или правая кнопка либо `Space` — панорама.

## Метки стыковки

Генератор соединяет комнаты через метки, которые стоят в дверных проёмах. Пара состыкованных
комнат оказывается лицом к лицу, между ними остаётся зазор `gap` клеток (стена).

- **Направленная метка** `a>b` стыкуется только с `b>a`. Например, прихожая `hall>kitchen` стыкуется с кухней `kitchen>hall`, поэтому две прихожие не соединятся через кухонные проёмы.
- **Простая метка** (`stair`, `corridor`) стыкуется только с такой же.
- **Режим `exact`** дополнительно требует одинаковую длину проёма.

Пресеты используют реальные размеры помещений серий 1-464, 1-335, 1-447, 1-468 и малосемеек:
кухни 5.9–6.2 м², совмещённые санузлы 2.6–3.5 м², залы 17–18 м². Проёмы тоже реальные:
0.7 м (санузел), 0.8 м (кухня), 0.9 м (комната), 1.0 м (входная), 1.3 м (двустворчатая в зал).

## Экономика

- **Валюты** — предметы с тегом `currency`: копейки, электронные компоненты, самогонка. Каждая кормит свой магазин.
- **Элитность** разыгрывается при заходе в комнату по весам `room.elite`. Тир задаёт лут, готовые предметы из магазинов и прирост опасности за проход.
- **Лут тира** задаётся ступенями «до N — P%». Они проверяются от большей к меньшей: первая сработавшая даёт от 1 до N штук.
- **Проходка** (за самогонку) умножает веса тиров от 2-го уровня и выше, а также шанс конкретного предмета.

## Для движка

Алгоритм генерации описан в `docs/GENERATOR.md`: ГСЧ, повороты, стыковка, порядок бросков и формат
экспорта прогона. По нему движок может повторить генерацию у себя по сиду или взять готовую
раскладку из JSON.

### Болванки для Babylon

`src/blockout/` — самодостаточная папка, её можно скопировать в прототип игры:

- `core.ts` превращает JSON прогона в непересекающиеся объёмы стен, перегородок, перемычек и колонн, а также полы, потолки, проёмы и тупики. От движка не зависит.
- `babylon.ts` строит из этого меши Babylon.js.
- `doors.ts` — каталог дверей по локациям и их процедурные модели (`BlockoutOptions.doors`); анимация открытия и бесшовность — `docs/DOORS.md`, галерея — `/tools/door-gallery.html`.

Описание алгоритма и разбор типовых проблем стыковки — в `docs/BLOCKOUT.md`, подключение к Babylon — в `docs/BLOCKOUT-BABYLON.md`, минимальный пример — `examples/babylon-demo/` (в dev-сервере: `/examples/babylon-demo/`).

### Игровой цикл

`src/game/` — логика прогулки без движка поверх того же JSON прогона: где лежат находки (на полу вне проходов, в мебели, на спотах), опасность при заходе в комнату и порог «уровень горит», карточка тира для игрока, инвентарь, сохранение. Описание — `docs/GAMEPLAY.md`.

### Кооп

Совместная «Прогулка»: вкладка «3D» → «Подключить онлайн» → создать лобби или войти по его UUID. Игроки видят друг друга, рядом друг с другом идут на 75% медленнее (сквозь друг друга пройти можно), двери и весь мир — общие. Relay-сервер — в `npm run dev` (путь `/coop`) или отдельно `npm run coop-server` (порт 8787, отдаёт и собранную игру). Описание — `docs/COOP.md`, код — `src/coop/`.

## Структура

```
src/model/    типы, геометрия клеток, отрезки, сериализация, операции, стор, ГСЧ
src/gen/      генератор раскладки и наполнения, мировая геометрия, правила для игрока
src/data/     пресеты: комнаты, мебель, предметы, экономика, процедурные текстуры
src/render/   камера холста, отрисовка декора, палитра
src/editor/   холст редактора комнаты, инструменты, список комнат, слои
src/panels/   инспектор, редактор вариантов
src/library/  библиотеки декора и предметов
src/economy/  тиры, карта элитности, магазины, проходки, опасность
src/preview/  предпросмотр прогона, сводка, экспорт
src/blockout/ болванки: ядро (JSON → объёмы без наложений) и адаптер Babylon.js
src/game/     игровой цикл прогулки: находки, опасность, карточка тира, инвентарь, сохранение
src/view3d/   вкладка «3D»
src/coop/     кооп «Прогулки»: лобби по UUID, копии мира по журналу операций, аватары (сервер — tools/coop-server.mjs)
src/spawn/    редактор спавнрейта
```
